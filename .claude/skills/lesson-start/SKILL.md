# 세션 시작 절차

사용자는 Godot 초보이고, 배우면서 함께 만들고 싶어 한다. 답은 **짧게** 한다.

## 1. 기록 읽기 (조용히, 요약해서 늘어놓지 않음)

1. `PROJECT_NOTES.md` → "⭐ 현재 상태 한눈에" 표, 가장 최근 "세션 기록" 1~2개, "위험 요소" 표에서 ⬜ 미확인 항목
2. `ROADMAP.md` → 맨 위 "📍 현재 위치" 줄, 그리고 **현재 Stage 부분만** (진행 순서, 체크 안 된 항목, 자주 막히는 곳)
3. `git status --short`와 `git log --oneline -3` → 마지막 세션 이후 바뀐 파일이 있는지 (다른 PC에서 작업했을 수 있음)

## 2. 환경 확인 (필요할 때만)

- `PROJECT_NOTES.md` "PC별 환경" 표에 지금 PC가 없거나 Godot 경로가 비어 있으면, 어느 PC인지와 Godot 설치 여부를 사용자에게 한 줄로 묻는다
- 다른 PC에서 작업한 흔적이 있으면 "OneDrive 동기화가 끝났는지(초록 체크)" 확인을 부탁한다

## 3. 사용자에게 안내 (5~8줄 이내)

형식:

```
지난번에는 ○○까지 했어요. (한 줄)
복습: △△는 □□였죠. (한 줄 — 지난번 배운 개념 하나)

오늘은 ◇◇를 해 볼까요? (ROADMAP 현재 Stage의 다음 체크 안 된 항목 1개)

첫 스텝: (에디터에서 할 구체적인 행동 하나, 메뉴 경로 포함)
```

- 오늘 목표는 **하나만** 제안한다. 사용자가 다른 걸 원하면 따른다
- 🚗 차 테스트가 밀려 있으면 (위험 요소 1번 등) 한 줄로 상기시킨다
- 현재 Stage가 🧠 고성능 모델 권장 구간이면 한 줄로 알린다
- 아직 코드를 길게 쓰지 않는다. 첫 스텝의 결과를 들은 뒤 진행한다
